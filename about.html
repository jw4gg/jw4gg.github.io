#Background

My dad was a systems administrator. We had multiple PCs around the house, networking gear in places it probably shouldn't have been, and servers humming in the background. Every couple of years we'd build new machines from parts.

One of my earliest computer memories is booting Crusader: No Remorse off a floppy in DOS as a kid. My dad got me into IT and that interest never really went away.

My formal background is Information Technology. I've done support, sysadmin work, and now data management. The pattern is the same in all three roles: something is wrong, figure out why, fix it without making things worse.

#What I work on

Most of my day job is structured data. Specifications written in XML, validated against schemas, transformed by Perl, queried with SQL. Not glamorous, but a surprising amount of the world still runs on this kind of plumbing.

After hours I mostly write Python. A Discord bot, scripts that pull data from APIs, glue code between systems that don't talk to each other natively. I started keeping a notes page to write some of it down.

#The homelab

One Proxmox host. A few Ubuntu server VMs, a TrueNAS VM for storage, and a handful of LXC containers. Docker lives inside one of the VMs so the Proxmox host stays clean. Portainer keeps me from forgetting which container does what.

Running today: reverse proxy, dashboards, media services, a Bitcoin full node, a self-hosted mining pool, backups, monitoring, the usual sysadmin furniture. There's a longer write-up on the homelab page.

One rule I try to keep: don't run anything I haven't at least skimmed the docs for. It has slowed me down more than once. Still worth it.

#Bitcoin, nodes, and a pool

The short version: more nodes is better. Bitcoin is interesting to me because the network is distributed by people choosing to participate in it, and I'd rather be one more of those people than not.

I run a full node and a small self-hosted pool I solo-mine to. The pool isn't going to outpace AntPool. That isn't why it's there. Solo mining to a pool of my own is a different kind of participation than just running a node, and both add a little redundancy to a network that benefits from it.

I also hold and occasionally trade some BTC and ETH. That part is separate from the infrastructure side.
