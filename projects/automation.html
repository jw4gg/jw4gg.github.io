~/projects/data & automation

Scripts that have been running longer than most of my hardware.

A growing collection of Perl and Python that moves, validates, and transforms structured data. Some of it I wrote yesterday. Some of it I wrote six or seven years ago and just haven't had to touch since.

#What's in here

This isn't a single project. It's the pile of scripts and small tools I've written and kept across different jobs and side projects. Most of them do something narrow and unglamorous:

  • Pull data from one system, validate the shape of it, hand it to another system.
  • Walk through a tree of XML, fix the broken bits, write it back out.
  • Query a database, reshape the rows, hand them to a downstream job.
  • Watch a directory, react when a file shows up, log what happened.

The kind of thing that doesn't make for an interesting screenshot but has saved a lot of hours.

#Why Perl is still here

A lot of the older scripts are Perl, and they're staying that way. Perl's regex story and its grip on text processing are still genuinely good. More importantly: these scripts work. They've been working for years. There's no business case for rewriting them in Python just because Python is the language I write more often now.

So they get cleaned up, documented a little better, and committed.

#What I'm doing with them now

Gradually pulling them out of various project folders and getting them into GitHub. Some need a quick scrub for embedded paths or credentials before they can go public. Some get a README I should have written when I wrote the script.

It's slow work. It's also the kind of work that's easy to put off, which is why I'm doing it on purpose.
